# Roadmap

[简体中文](./roadmap.zh-CN.md)

This roadmap is written for public readers on GitHub. It focuses on where the project is going, not just internal phase tracking.

## Positioning

This project is evolving along two parallel tracks:

1. **Research and documentation**
   - make Harness Engineering easier to study and understand
2. **Runnable MVP**
   - provide a lightweight, practical Agent Harness prototype

## Completed

### Research foundation

- core concept summaries
- design pattern extraction
- comparative analysis of `claude-code-harness`, `refact`, and `agent-os`
- translated and summarized theory materials

### MVP core loop

- `plan` task management
- `work` execution in solo and parallel modes
- `review` multi-angle code review
- lightweight file-based state management

### Quality and usability improvements

- stronger test coverage across core modules
- custom review rules
- dependency graph generation and visualization
- incremental review based on Git changes
- task templates and reusable workflows

## In Progress

### GitHub-facing polish

- cleaner English landing pages
- bilingual entry structure
- better navigation across research, design, and usage docs
- a roadmap that external readers can understand quickly

### Onboarding quality

- faster first-run path
- clearer quick-start documentation
- stronger separation between public entry docs and deep Chinese content

## Planned

### Short term

- improve repository presentation for discoverability and stars
- add clearer demo materials and usage showcases
- refine documentation hierarchy and public-facing storytelling
- add stronger example-driven onboarding

### Medium term

- role-based model configuration improvements
- better performance tracking and bottleneck analysis
- richer execution observability
- stronger MVP ergonomics and CLI experience

### Longer term

- real-world usage validation on external projects
- more reusable patterns for teams adopting harness-style workflows
- stronger public examples and case studies

## Non-Goals for Now

To keep the project focused, these are intentionally not the immediate priority:

- turning the MVP into a large production platform
- building a complex distributed execution system
- optimizing for heavy enterprise-scale infrastructure
- replacing mature AI IDE products directly

## Success Signals

The project is moving in the right direction if it becomes:

- easier to understand from the GitHub landing page
- easier to try in under 10 minutes
- more useful as a study resource
- more reusable as a lightweight harness reference implementation
