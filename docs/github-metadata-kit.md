# GitHub Metadata Kit

This document prepares the exact repository metadata you can paste into GitHub settings.

It is designed to keep the repository's public positioning consistent with the current README:

- research-driven
- runnable
- small enough to inspect
- stronger in English discovery, deeper in Chinese implementation notes

## Recommended Repository Description

Use this as the primary GitHub description:

```text
Research-backed Harness Engineering study repo with a runnable Python MVP built around Plan -> Work -> Review.
```

If you want a slightly more discovery-oriented variant:

```text
Harness Engineering study repo with research notes, a runnable Python MVP, and example workflows built around Plan -> Work -> Review.
```

## Recommended Website Field

If you keep the Website field empty, that is fine for now.

If you want a repo-internal landing target, use:

## Consistency Rules

When editing GitHub settings, keep these aligned with the README:

- do not describe the repo as a framework platform
- do not oversell it as production-ready infrastructure
- do describe it as research-backed and runnable
- do keep `Plan -> Work -> Review` visible whenever space allows

## Recommended Manual Update Order

Apply the metadata in this order:

1. Description
2. About blurb
3. Topics
4. Social preview image
5. Optional Website field
