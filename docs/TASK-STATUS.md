### 6. ✅ 支持自定义审查规则 (P1)
**完成日期**: 2026-06-07  
**优先级**: P1 (中)  
**状态**: ✅ 已完成  
**实际工作量**: 1 天

#### 功能
- 配置文件定义规则 (`custom_rules.json`)
- 支持正则表达式匹配代码模式
- 支持文件 glob 模式过滤（如 `*.py`, `src/*.js`）
- 每条规则可配置 severity/category/message/suggestion
- 支持启用/禁用规则切换
- 与现有审查流程无缝集成

#### 新增文件
- `harness/custom_rules.py` — 规则存储 + 引擎 (78 行, 100% 覆盖率)
- `tests/test_custom_rules.py` — 33 个测试用例

#### CLI 命令
- `harness review rule add <name> --pattern <regex> --message <msg>` — 添加规则
- `harness review rule list [--category <cat>]` — 列出规则
- `harness review rule remove <name>` — 删除规则
- `harness review rule toggle <name>` — 启用/禁用
