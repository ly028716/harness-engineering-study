# Launch Kit

This document packages reusable outreach copy for sharing the repository outside GitHub.

The goal is not to sound like a startup landing page. The goal is to help more developers quickly understand why this repository is worth opening, starring, and following.

## Positioning

Use this framing consistently:

- **Category**: Harness Engineering study + runnable Python MVP
- **Core loop**: `Plan -> Work -> Review`
- **Difference**: English-friendly discovery layer, deeper Chinese research and implementation notes
- **Why it is worth starring**: it is both a learning surface and a small inspectable reference implementation

## GitHub Update Post

Use this when posting a repo update in GitHub Discussions, release notes, or as the base copy for a README-oriented share.

```text
I have been turning this repository into a more usable public learning resource for Harness Engineering.

What is inside:
- research notes across OpenAI, Anthropic, claude-code-harness, refact, and agent-os
- a runnable Python MVP built around Plan -> Work -> Review
- example scenarios that show how a harness can structure real engineering tasks

Recent improvements:
- a stronger English GitHub entry layer
- a cleaner documentation gateway
- a featured auth-flow showcase for first-time visitors

If you are exploring AI-assisted engineering workflows and want something smaller and more inspectable than a heavy framework, this repo may be useful:
https://github.com/ly028716/harness-engineering-study
```

## Reuse Checklist

Before posting, quickly adapt these fields:

- replace "I have been" with your preferred voice
- choose one featured example: usually `auth-flow`
- mention the latest visible improvement, not every improvement
- keep the CTA simple: repo link + star / feedback invitation

## Recommended First Link Targets

Depending on the audience, point them to:

- repo homepage: `README.md`
- example-driven visitors: `examples/auth-flow/README.md`
- implementation-driven visitors: `harness-mvp/README.md`
- documentation-driven visitors: `docs/README.md`
